# Quarsell — сайт-портфолио

Одностраничный сайт с 3D-фоном (Three.js) и четырьмя живыми демо-проектами. Работает без сборки и без сервера.

## Структура
```
index.html          разметка всех разделов
css/style.css       основные стили
css/demos.css       стили мини-демок
js/config.js        КОНТАКТЫ (Telegram, почта) — редактировать тут
js/main.js          меню, анимации, панели 3D-комнаты
js/projects.js      описания проектов и модальное окно с демками (общее для обеих версий)
minimal/            вторая версия сайта: минималистичная (index.html, minimal.css, minimal.js, glass.js — 3D-капля стекла на первом экране). Версии не ссылаются друг на друга. После правок в minimal/ увеличь номер ?v= у файлов в minimal/index.html и minimal.js
js/room/            3D-сцена (Three.js 0.186.1 с jsDelivr)
js/demos/*.js       демки: tg-bot, landing, discord, crm, qr-menu, configurator, dashboard, shop-bot
assets/favicon.svg  иконка вкладки
```

## Как поменять контакты
Открой `js/config.js` и впиши свой ник в Telegram (без @) и почту. Все кнопки на сайте обновятся сами.

## Запуск локально
Из-за ES-модулей открывать `index.html` двойным кликом нельзя, нужен локальный сервер:
```bash
cd quarsell-portfolio
python3 -m http.server 8080
```
Потом открой http://localhost:8080

## Хостинг: GitHub Pages
Сайт живёт в репозитории `playciber14-maker/playciber14-maker.github.io` и открывается по адресу https://playciber14-maker.github.io

Как обновить сайт после правок:
```bash
git add -A
git commit -m "что поменял"
git push
```
Через 1–2 минуты изменения появятся на сайте.

## Как добавить свой проект
Скопируй блок `<article class="project ...">` в `index.html`, поменяй текст. Если демки нет, кнопку «Открыть демо» можно заменить ссылкой на живой проект.

## Заметки
- На слабых устройствах 3D автоматически облегчается, без WebGL показывается градиент.
- При включённом «уменьшении движения» в системе анимации отключаются.
- Все проекты помечены как «Демо-проект»: компании и цены в них вымышленные.
